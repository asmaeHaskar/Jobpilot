=====================================
   TROUBLESHOOTING
=====================================

App won't start?
  → Kill server: Ctrl+C
  → Restart: npm run dev

Email not confirmed?
  → Restart dev server
  → Or create new account

Tables not found?
  → Visit: http://localhost:3000/setup
  → Auto-initializes

Env variables not loading?
  → Check .env.local exists
  → Restart dev server
